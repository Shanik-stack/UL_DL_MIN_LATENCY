# Downlink Exhaustive Search

The recovered Downlink source history contains result artifacts for exhaustive
comparisons but not the corresponding validator implementation. This folder is
kept as the reserved location for a future recovered or independently verified
Downlink exhaustive benchmark. It is intentionally not a runnable method.

The runnable exhaustive validator is currently available for Uplink only:
`latency_optimization/uplink/benchmarks/exhaustive_search/`.
