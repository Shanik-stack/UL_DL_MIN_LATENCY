# Uplink Monte Carlo Configuration

Use `uplink_dispersion_heavy.yaml` for payload or `uplink_streaming.yaml` for
streaming.

For payload, `monte_carlo_num_training_channels` is the number of independent
seed-based channel episodes. Later blocks are generated by the payload rollout.
For streaming, `monte_carlo_num_training_blocks` is the number of independent
seed-based one-block samples. Use `monte_carlo_num_test_channels` or
`monte_carlo_num_test_blocks` according to the scenario. The model is trained
with objective-only FBL rate and visits its `n_kl` states through rollout.
The streaming block count is direct and is not multiplied by
`experiment_scenario.number_of_blocks`.
